## 📝프로젝트 소개
2024년 LX 공간정보 아카데미 최종프로젝트 **국토교통부 장관상(대상)** 수상작 입니다. 
"등산 위험요소 안내 및 대응"을 주제로 한 어플리케이션과 웹 페이지를 제작했습니다.

## 🤔 프로젝트 개요
> LX공간정보 아카데미 최종 발표회에서 안전 등산을 주제로 프로젝트 진행함.
등산 인구의 증가에 따라 등산사고 발생 건수도 꾸준히 늘고 있지만. 현재 등산 관련 앱들은 커뮤니티와 기록 기능에 초점이 맞춰져 있음. 등산 안전 정보를 제공하는 앱은 부재한 상황에서, 등산객들에게 안전한 코스 선택, 사고 예방, 그리고 신속한 사고 대응을 돕는 종합 등산 안전 플랫폼을 개발하고자 함.

## 💁‍♂️ 프로젝트 팀원
![image](https://github.com/user-attachments/assets/154de8bb-fa7f-4f78-b039-14f07e5a4f08)

### 😎최용혁(팀장)

- **UI**
    - 페이지 : 등산 시뮬레이션 페이지, 유동인구 핫스팟 분석 페이지, 프론트엔드 보조
- **기능**
    - 등산로 코스 조회, 등산로 위험구간 시각화, 경사도 시각화, 3D 등산 시뮬레이션, 위험구역 음성안내(TTS), 등산 유동인구 히트맵 조회
<br>

### 😎김홍재

- **UI**
    - 페이지 : 프론트엔드 보조, sos비상알림 페이지
- **기능**
    - sos 비상알림 전송 및 수신, 국가기본도 시각화 및 조회
<br>

### 😎박정은

- **UI**
    - 페이지 : 등산 기록 페이지, 민원 페이지, 코스 비교 페이지
- **기능**
    - 등산 기록 저장 및 조회, 민원 CRUD, 코스 비교 조회
<br>

### 😎이아민

- **UI**
    - 페이지 : 커뮤니티 페이지, 민원 히트맵 페이지
- **기능**
    - 커뮤니티 CRUD(지도 기반) 및 커뮤니티 지도 시각화
<br>

### 😎최수환

- **UI**
    - 페이지 : 코스 리뷰 페이지, 코스 미리보기 페이지
- **기능**
    - 영상을 통한 코스 미리보기 기능, 리뷰 CRUD 및 kobert 모델을 활용한 댓글 요약
<br>

### 😎최지욱

- **UI**
    - 페이지 : 전체 프론트엔드 총괄
- **기능**
    - 실시간 유동인구 조회
<br>
